CÓMO GENERAR EL APK DESDE GITHUB
1. Sube/reemplaza todos los archivos de este paquete en el repositorio.
2. Haz commit y push a la rama main.
3. En GitHub abre Actions.
4. Busca: Android APK - PUNTO YA CR.
5. Espera a que termine en verde.
6. Abre la ejecución y baja el artefacto: PUNTO-YA-CR-debug-apk.
7. Descomprime el artefacto. Dentro estará app-debug.apk.
8. Instálalo en un Android de prueba.

Este APK es DE PRUEBA. Está firmado automáticamente con la clave debug de Android.
NO se debe subir ese APK a Google Play.
