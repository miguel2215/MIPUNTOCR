MI PUNTO CR v7.17 - PRUEBA 3

ORDEN:
1. Ejecuta SQL-v7.17-PRUEBA-3-PRO.sql en Supabase SQL Editor UNA sola vez.
2. Publica todos los archivos de este ZIP en GitHub.
3. Cloudflare debe usar: npx wrangler deploy
4. Inicia sesión como Dueño.
5. Configuración > Mi Punto CR Pro > Ver Pro > código promocional.
6. Para esta prueba usa: PRO-V717-TEST (solo funciona una vez y da 30 días Pro).
7. Debe mostrar CR1000 para el Dueño.
8. Configuración > Empleados Pro > crea el primer empleado. Debe recibir CR1001.
9. Haz una venta como empleado y revisa que quede asociado a ese empleado.

IMPORTANTE:
- El código PRO-V717-TEST es únicamente para esta prueba.
- Los futuros códigos se generarán desde el Panel Maestro y serán únicos de un solo uso.
- No borres ventas históricas al eliminar un empleado.
