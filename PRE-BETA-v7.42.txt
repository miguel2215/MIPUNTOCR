PUNTO YA CR v7.42 PRE-BETA

BASE RESPETADA
- Parte de v7.41 PRE-BETA.
- No reemplaza módulos operativos que ya funcionan.
- Beta limitada a Restaurante y Retail. Servicios permanece oculto.

INCLUIDO EN v7.42
- Panel del Emprendedor simplificado para móvil y PC.
- Encabezado más compacto y navegación móvil con accesos principales + Más.
- Configuración organizada por tarjetas: Datos del negocio, Logo e imagen, Tipo de negocio, Impresión, PRO, Cuenta y acceso y Factura electrónica.
- Cambio Restaurante <-> Retail disponible durante PRE-BETA para el Dueño.
- El cambio de tipo NO borra datos del otro modo.
- Panel usa el tipo activo para separar visualmente ventas e inventario de Restaurante/Retail.
- PUNTO YA CR PRO desde el Panel con dos caminos: Obtener PRO y Activar código PRO.
- Activación por código usa la RPC existente redeem_pro_promo_code y refresca el estado real con get_my_business_plan.
- PRO se consulta desde Supabase para el negocio, no solo desde una etiqueta visual.
- Botones de pago muestran los planes actuales, pero NO realizan cargos todavía; el checkout real sigue pendiente.
- Opciones sensibles (cambio de tipo y activación/compra PRO) restringidas al Dueño en el Panel.
- Carga de logo simplificada: botón Agregar/Cambiar logo y selector técnico oculto.
- Impresión automática: intenta reconocer impresoras ya autorizadas USB y, cuando el navegador lo permite, selección Bluetooth.
- Si el modelo permite inferir el formato, configura el ticket automáticamente.
- Si no puede identificar el formato, hace una prueba guiada sin pedir al usuario conocer 58/80 mm.
- La app operativa deja de mostrar el selector técnico 58/80 mm y usa Buscar impresora / Imprimir prueba.
- La configuración detectada se guarda y se sincroniza en settings cuando hay nube.
- Android: versionCode 742 / versionName 7.42.0.
- Caché actualizado a v7.42.
